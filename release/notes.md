- **Two corrections to how this machine takes updates.** Neither changes anything
  you use; both are about the machinery being honest with itself.

  The update now runs from a fixed location rather than a temporary one, so the
  note this machine keeps about where its installed skills came from names
  somewhere that still exists and stops changing after every update.

  And it now asks for the current release list rather than accepting a cached
  answer. Without that, a machine could be told nothing was available for up to
  five minutes after a release was published, which matters most when somebody
  here has just been told there is one and applies it by hand.
