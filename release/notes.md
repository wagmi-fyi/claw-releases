- **A correction to how this machine records where its software came from.**
  Release 1.0.0 applied itself out of a temporary folder, so the note this machine
  keeps about the source of its installed skills pointed at a folder that had
  already been deleted, and it said something different after every update. The
  update now runs from a fixed location that stays in place, so that record names
  somewhere real and stops changing on its own.

  Nothing you use was affected. This is about the machine's own bookkeeping being
  accurate rather than about anything you would have noticed.
